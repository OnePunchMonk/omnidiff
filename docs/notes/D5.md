# D5: student export bundle

`omnidiff export --ckpt <checkpoint dir> --out <bundle dir>` writes a bundle from an omnidiff
checkpoint (typically a distilled student). `omnidiff.distill.export.load_bundle(path)` returns a
core `Pipeline` from it; samples match `Pipeline.from_checkpoint` bit for bit on CPU with the same seed.

## Files

| file | content |
| --- | --- |
| `model.safetensors` or `model.pt` | plain state dict, LoRA merged. safetensors is used when importable (extra `omnidiff-distill[export]`), otherwise `torch.save` |
| `model.json` | the model spec, exactly the checkpoint's `model` config (includes `two_time`, noise-conditioned token adapter settings) |
| `sampler.json` | sampling recipe, below |
| `README.md` | how to sample |

## sampler.json (schema_version 1)

Required keys:

- `schema_version`: int, 1.
- `process`: `{"type": str, "settings": {...}}`, the process registry name and its constructor settings, without the sampler.
- `sampler`: str or null, e.g. `renoise`, `ode`, `coupled`.
- `timesteps`: descending list of floats from 1 to 0, or null (then `num_steps` and the process default grid apply).
- `num_steps`: int.
- `guidance_scale`: float.
- `sample_shape`: list of int, per-sample shape in process space.
- `codec`: registry spec (name or dict) used to decode samples.
- `prompts`: registry spec for the prompt source.

Optional keys:

- `distilled_from`: `{teacher, method, teacher_guidance, steps}`, provenance written by the distill trainer.
- `plugins`: list of plugin names to load before building.

`load_bundle` rejects a missing required key or an unknown `schema_version`.
