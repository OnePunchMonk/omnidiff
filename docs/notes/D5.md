# D5: student export bundle

`omnidiff export --ckpt <checkpoint dir> --out <bundle dir>` writes a bundle from an omnidiff
checkpoint (typically a distilled student). `omnidiff.distill.export.load_bundle(path)` returns a
core `Pipeline`; samples match `Pipeline.from_checkpoint` bit for bit on CPU with the same seed.
The schema and sampling semantics are also written into each bundle's `README.md`.

`load_bundle` imports the plugin modules named under `plugins` in `sampler.json`, so only load
bundles you trust.

## Files

| file | content |
| --- | --- |
| `model.safetensors` or `model.pt` | plain state dict, LoRA merged. safetensors when importable (extra `omnidiff-distill[export]`), otherwise `torch.save`. Exactly one is present; a re-export removes the other |
| `model.json` | the checkpoint's `model` config (includes `two_time` and noise-conditioned token adapter settings) |
| `sampler.json` | sampling recipe, below |
| `resources/` | files referenced by `path` keys in the codec or prompt specs, copied at export |
| `README.md` | how to sample, schema, sampling semantics |

## sampler.json (schema_version 1)

Required keys:

- `schema_version`: int, 1.
- `process`: `{"type": str, "settings": {...}}`, registry name and constructor settings, without the sampler.
- `sampler`: str or null, e.g. `renoise`, `ode`, `coupled`.
- `timesteps`: strictly descending numbers from 1 to 0, or null (then `num_steps` and the process default grid apply).
- `num_steps`: int; equals `len(timesteps) - 1` when `timesteps` is given.
- `guidance_scale`: float.
- `sample_shape`: list of positive ints, per-sample shape in process space.
- `codec`, `prompts`: registry specs. Strings under `path` or `*_path` keys are bundle-relative.
- `weights`: `{"file", "format" ("safetensors" or "torch"), "sha256"}`. `load_bundle` reads exactly this file and checks the hash.

Optional keys:

- `distilled_from`: `{teacher, method, teacher_guidance, steps}`. `teacher` is the last two components of an absolute path, or the path as written if relative.
- `plugins`: plugin modules to import before building.

`load_bundle` raises `ValueError` naming the offending key for any violation.
