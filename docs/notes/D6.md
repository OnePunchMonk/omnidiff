# D6: multi-seed distillation report

`scripts/distill_toy_report.py --seeds ...` trains each student once per seed against a fixed teacher, scores every
seed with the same prompts and settings, and aggregates with `diffusion_omni.reward.aggregate`.

## Statistics

- Cells are mean ± sample std (n - 1) over seeds. A std needs at least two values.
- `(k/N)` marks a cell fed by fewer than the N planned seeds (a failed run or a NaN metric). Failed runs are
  listed under the table and the script exits non-zero.
- `reference` rows are deterministic: no std.
- The evaluation seed is fixed, so the std is training-seed variance only. Sampling noise in the metrics at the
  chosen n is not measured.

## Run directories and provenance

- Seed `s` of student `<name>` goes to `<runs-root>/<name><suffix>_s<s>` (default `runs/distill`). `--set` smoke
  runs default to `runs/distill_smoke`.
- Each trained run writes `provenance.json`: resolved distill config (with `--set` extras), seed, teacher path,
  teacher `model.pt` mtime and size, and mtime and size of the distill config file, the method source and
  `distill/trainer.py`.
- A run is skipped only if that file matches exactly. A run with a `model.pt` and a different or missing
  `provenance.json` is stale: the script prints the differing key and stops, unless `--retrain-stale` is given.
- `--reuse-seed0` is opt-in. It uses `runs/distill/<name><suffix>` as seed 0 only if: no `--set` extras;
  `distilled_from.teacher/method/steps/teacher_guidance` equal the resolved config; saved seed is 0; and its
  `model.pt` is newer than the teacher `model.pt`, the distill config file and the method and trainer sources.
  Otherwise it prints why and trains seed 0 afresh.

## Teachers

The teacher checkpoint is `output_dir` of `configs/<group><suffix>.yaml` plus `/sft/final`, and must contain
`model.pt`. Missing teachers fail the run unless `--allow-missing` is given; the report then lists the skipped
groups. Only the image and video flow groups have `_ts10` configs, so pass `--groups` for the ts10 run.
`runs/image_flow_ts10/sft/final` exists; `runs/video_flow_ts10` needs
`uv run diffusion-omni sft -c configs/video_flow_grpo_ts10.yaml` first (8000 steps).

## Planned runs (3 seeds)

- Default teachers: 12 students x 3 seeds = 36 runs (image flow 6, ddpm 1, video 2, text 3).
- ts10 teachers: 8 students x 3 seeds = 24 runs (image flow 6, video 2).

## Commands

```
uv run python scripts/distill_toy_report.py --seeds 0 1 2 --dry-run
uv run python scripts/distill_toy_report.py --seeds 0 1 2
uv run diffusion-omni sft -c configs/video_flow_grpo_ts10.yaml
uv run python scripts/distill_toy_report.py --seeds 0 1 2 --teacher-suffix _ts10 --groups image_flow_grpo video_flow_grpo --dry-run
uv run python scripts/distill_toy_report.py --seeds 0 1 2 --teacher-suffix _ts10 --groups image_flow_grpo video_flow_grpo
```

Add `--reuse-seed0` only if the pre-existing single-seed runs are still valid for the current code.
