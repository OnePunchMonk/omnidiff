# D4: single-mask discrete consistency distillation for masked text (`dcd`, an ablation)

Scope: this is a single-mask, factorised-target ablation. The multi-mask / shared-Gumbel scheme of 2607.19686 is not implemented, and a weak few-step result is expected for a factorised target.

## Reading

The acceptance item "read the papers" was NOT met: only the arXiv abstract pages could be fetched (as summaries by the fetch tool, not verbatim). Neither full paper was read, so the design below is justified from first principles and is not a reproduction of either paper.

- **2607.19686**, "Multi-Mask Diffusion Language Models for Few-Step Generation" (Chen, Ren, Zhao, Cheng, Gu, Ying). Abstract: a masked diffusion model sends every forward trajectory to one fully masked state, which hurts few-step generation. MultiMDM mixes clean tokens over a set of masks so the reverse process can draft a mask before refining it; gives a closed-form ELBO usable for continued training of pretrained MDMs; and a purely discrete consistency distillation with a shared-Gumbel coupling that reduces pathwise entropy. Not implemented here: the multi-mask process and its ELBO need a model with several mask tokens, and our teacher has one.
- **2609.33947**, "Simple Diffusion Language Models Are More Effective Few-Step Generators Than Reported" (Amin, Yin, Khanna). Abstract: much of the few-step gap is sampler configuration; temperature 1 is suboptimal under parallel unmasking; quality and across-output diversity must be scored jointly (GroupEval). Consequence for us: the comparison includes a `T0.6` temperature-tuned teacher, and valid/coverage/diversity are reported together.

## Objective

For x0 from the SFT data, t ~ U(0.05, 1), x_t = q_sample(x0, t). Draw s = 0 with probability 0.25, else s ~ U(0, t). Run `sub_steps` (2) teacher ancestral steps x_t -> x_s. Target for each position masked in x_t:

- decoded by the teacher on the way: one-hot on its token (f(x_s, s) is a point mass there);
- still masked at s: softmax of the EMA target network at (x_s, s).

Loss: KL(target || student(x_t, t)) averaged over positions masked in x_t. Target network: EMA (decay 0.95) of the student, initialised from the teacher; gradients never flow through it. One network serves every step count, since s is random.

How each concern is handled:

- **Masked-token coupling.** The teacher steps use independent per-position draws, exactly as the teacher samples. The target for a masked position is conditioned on the tokens the teacher drew for others in the same interval (via x_s), which a one-step per-position prediction otherwise ignores; this is the same mechanism as SDTT. It is still a per-position marginal target, so it cannot reproduce the joint dependence among simultaneously decoded tokens (that is what `coupled_kd` buys with noise input). The shared-Gumbel coupling of 2607.19686 is not used.
- **Remasking.** The absorbing process never remasks: decoded tokens are carried over. The target treats decoded positions as final (one-hot) and only masked ones take the network's distribution. The mask token is excluded from all distributions by `log_probs`.
- **Temperature.** Teacher steps use `tr.teacher_process` (the teacher's own temperature); target and student distributions go through `process.log_probs`, so the same temperature applies to both. No sharpening is introduced; the `T0.6` reference variant in the scorecard shows how much of the gain is sharpening alone.
- **Prefix and loss masks.** Maskable positions are `loss_mask` (if present) AND `prefix < 0` (if present); a loss mask never unprotects a prefix. Teacher steps go through `tr.teacher_pred`, which honours `teacher_guidance`; the toy text teacher has no CFG branch, so a test only checks the call path. The target network is a copy of the post-LoRA student, EMA-updated by state_dict key, so LoRA students work (tested). The experiment below ran before these patches; they do not change the non-LoRA, unit-guidance computation. Prefix positions are never masked, so they are never targets and the teacher steps leave them alone. Conditioning is passed through to the teacher, target and student unchanged.
- **Fixed point and boundary.** If student = target on every pair, the loss is zero. At s = t no teacher step happens, so the target equals the target network at (x_t, t) and a student equal to it has exactly zero KL (tested; a perturbed student has positive KL). At s = 0 every masked position becomes a one-hot at the teacher's sampled token, anchoring the objective to the teacher (tested). A fixed point of the EMA recursion satisfies f(x_t) = E over teacher paths of the target mixture. For a self-consistent teacher that equals the teacher's own one-step per-position marginal p(x0_i | x_t), because the multi-step chain marginal of a consistent teacher is its one-step marginal. So the fixed point is the teacher itself, and a factorised single-mask target cannot beat the teacher by construction (the same bound as SDTT-style marginal distillation). The Monte Carlo test checks this with an exactly self-consistent stand-in teacher (prediction independent of x and t): the mean target over 8192 paths matches the marginal within 0.03, for 1 and 2 sub-steps. For the real toy teacher, which is only approximately self-consistent, it is a property of the objective, not a proof of convergence.

## Result

Negative. `dcd` is indistinguishable from the undistilled teacher at the same step count (valid 0 / 0.03 / 0.19 / 0.36 against 0 / 0.02 / 0.18 / 0.37) and far below `coupled_kd` at 1 and 2 steps (valid 0.44 / 0.50). The T0.6 teacher is better than dcd at 4 and 8 steps, so the change in this run is not distinguishable from a sampler setting. The training KL sits near 0.16 from step 100 to 3000. A diagnostic added afterwards, `kl_to_teacher` = KL(teacher one-step || student) on each step's fresh x_t, was 0.015 to 0.019 over a 600-step rerun (the 3000-step run was made without it): the student sits close to the teacher's marginal, which is the fixed point, rather than failing to train. That is why `dcd` matches the teacher curve. The flat dcd_kl value is expected, not a failure signal: targets for decoded positions are sampled one-hots, so the KL has an irreducible floor. The student's one-step independent draws also cannot reproduce joint structure. Sampling noise at n = 256 is a few points on valid, and this is a single seed.

Not tried (each would be a separate change): a multi-mask teacher, shared-Gumbel coupling of the sampled paths, larger `sub_steps`, a noise-conditioned student, 2609.33947-style sharpened targets.
