# Three-seed summary of the toy distillation runs

Source: [distillation_toy_seeds.md](distillation_toy_seeds.md) (generated by `scripts/distill_toy_report.py --seeds 0 1 2`; raw rows in `runs/scorecards/*_seeds.json`, not committed). 20 students x 3 seeds = 60 runs, teachers fixed (the `time_scale` 1000 teachers), n = 512. Cells are mean ± sample std over training seeds. The evaluation seed is fixed, so the spread is training-seed variance only. Data FD is the Fréchet distance to real data in fixed random features (lower is better); it is not comparable with published FID.

## What the three seeds confirm

1. **Text: `coupled_kd` is the only method that fixes few-step masked decoding.** Valid-line rate at 1 / 2 / 4 / 8 steps is 0.45 / 0.55 / 0.65 / 0.72 (std 0.01 to 0.03), against 0.00 / 0.01 / 0.15 / 0.39 for the undistilled teacher and 0.00 / 0.03 / 0.20 / 0.47 for the best tuned teacher (T = 0.6). KD is only marginally above the tuned teacher (0.06 / 0.27 / 0.49 at 2 / 4 / 8 steps), the single-mask `dcd` matches the teacher (0.02 / 0.20 / 0.43), and SDTT is no better than the undistilled teacher at 1 step and worse from 2 steps on.
2. **Image flow: KD wins at 1 to 2 steps, a tuned teacher wins from 4.** Data FD of KD is 0.143 / 0.178 / 0.230 / 0.195 at 1 / 2 / 4 / 8 steps, against 1.22 / 0.34 / 0.19 / 0.14 for the teacher with shift 3.
3. **Flow map on the `time_scale` 1000 teacher behaves like the teacher's Euler sampler** (data FD 1.23 / 0.62 / 0.36 / 0.22, within noise of the teacher). This reproduces the earlier single-seed finding; the fix is a smoother teacher (see `distillation_toy.md`).
4. **Gaussian DMD2 does not fail any more but is not good**: data FD 3.2 / 1.4 / 2.5 / 5.3 against 25.7 / 7.3 / 1.6 / 1.1 for the teacher, so it helps at 1 to 2 steps only.

## What is new

5. **Progressive distillation works and is stable across seeds.** Image flow: data FD 0.246 / 0.162 / 0.186 / 0.186 (std below 0.001), so it beats the tuned teacher at 1 and 2 steps. Image DDPM: 15.4 / 1.88 / 0.496 / 0.484, which beats the best teacher sampler (0.90) from 4 steps on. This is the best result for the Gaussian teacher so far. Its std is very small, but only 3 seeds.
6. **DMD2 is still best at 2 steps on the flow teacher** (data FD 0.254 at 2 steps against 0.292 at its 4-step grid, and 1.33 at 8 steps), even with `last_stage_prob: 0.5`. The single-seed 240-step result of D1 (best at the trained grid) does not carry over to full training with 3 seeds. The stage-sampling change therefore is not a fix for the grid mismatch; the cause is still open. The GAN head does not change this (0.246 / 0.247 at 2 / 4 steps).
7. **Video: flow map equals the teacher, DMD2 is flat across step counts** (0.55 / 0.54 / 0.52 / 0.84), better than the teacher at 1 step only.

## Limits

- Three seeds; with n = 3, a sample std is itself noisy.
- One evaluation seed, so evaluation sampling noise is not included in any spread.
- In-training `eval_*` values logged before the evaluation-noise fix (`docs/notes/EV.md`) are optimistic for noise-conditioned students. The tables here come from the scorecard and are not affected.
- The `time_scale` 10 teachers are not covered here (second report, still to run).
